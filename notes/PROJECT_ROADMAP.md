# Project Roadmap

## Mission

Build a personal, educational OnionShare-compatible application by first
understanding the upstream architecture, then incrementally refactoring
or replacing components while preserving behavior.

## Phases

1.  Reverse engineer upstream.
2.  Document every subsystem.
3.  Build a minimal compatible core.
4.  Refactor into a cleaner architecture.
5.  Add new features.
6.  Package and test.

## Milestones

-   Repository study
-   Startup sequence
-   Tor controller
-   Web server
-   Share mode
-   Receive mode
-   Website mode
-   Chat mode
-   GUI
-   Packaging
